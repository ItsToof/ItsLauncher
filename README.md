# ItsLauncher

Лаунчер Minecraft на Tauri 2 и React: экземпляры, сборки и моды с Modrinth, Fabric, Forge, NeoForge и Quilt, аккаунты Microsoft, Ely.by и офлайн, автоматическая загрузка Java.

## Скачать

Установщик для Windows лежит в разделе [Releases](../../releases/latest).

## Сборка из исходников

Нужны Node.js 20+, Rust (stable) и зависимости Tauri для Windows: https://tauri.app/start/prerequisites/

```
npm install
npm run tauri dev
```
